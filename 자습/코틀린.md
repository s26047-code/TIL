### 변수 선언
#### <mark>자바</mark>
```gradle
int a = 5;
String b = "배고파";
final int c = 6;
```
a는 int형 5    
b는 문자열 "배고파"    
c는 int형이고 불변하는 6

이라는 뜻의 자바 변수 선언이다.

<br>
<br>

#### <mark>코틀린</mark>
```kotlin
val a = 5
val b = "배고파"
var c = 6
```
위와 같은 의미의 코틀린 문법의 변수 선언이다.

<br
> 변수이름 : 타입 = 변수  
ex) val i : Int = 5

순서로 작성하는 것이 일반적이나, 위처럼 생략이 가능하다!

### 조건문

#### <mark>자바</mark>

```gradle
int a = 5;

if (a > 3) {
    System.out.println("3보다 크다");
} else {
    System.out.println("3보다 작거나 같다");
}
```

a가 3보다 크다면 "3보다 크다"를 출력하고, 그렇지 않다면 "3보다 작거나 같다"를 출력하는 자바 조건문이다.

<br>
<br>

#### <mark>코틀린</mark>

```kotlin
val a = 5

if (a > 3) {
    println("3보다 크다")
} else {
    println("3보다 작거나 같다")
}
```

위와 같은 의미의 코틀린 문법의 조건문이다.

<br>

코틀린의 if문은 자바와 거의 동일하게 사용할 수 있으며, **System.out.println() 대신 println()을 사용**한다고 한다.

또한 코틀린에서는 if문 자체를 하나의 값처럼 사용할 수 있다!

<br>

예시를 들자면 
```kotlin
val result = if (a > 3) {
    "3보다 크다"
} else {
    "3보다 작거나 같다"
}
```
이 코드가 조건을 충족한다면 result에 "3보다 크다"라는 문자열이 저장된다는 것이다.

당연하게도 충족하지 않는다면 else문으로 내려와 result 값은 "3보다 작거나 같다"가 된다!

### 반복문
#### <mark>자바</mark>

```gradle
for (int i = 0; i < 5; i++) {
    System.out.println(i);
}
```
자바의 for문이다.

<br>
<br>

#### <mark>코틀린</mark>

```kotlin
for (i in 0 until 5) {
    println(i)
}
```

같은 의미의 코틀린 문법의 반복문이다. 

코틀린에서는 자바처럼 초기값; 조건식; 증감식을 작성하지 않고,

> for (변수 in <mark>범위</mark>) {}
형식으로 작성한다.

<br>
<br>

**범위의 문법으로는 아래와 같은 표현식이 있으니 참고해서 사용하도록 하자.**   

`..` -> 시작 값부터 범위 값까지 1씩 증가
> ex) 0..5
→ 0, 1, 2, 3, 4, 5

<br>

`until` -> 시작 값부터 범위 값 미만까지 1씩 증가
> ex) 0 until 5
→ 0, 1, 2, 3, 4

<br>


`downTo` -> 시작 값부터 범위 값까지 1씩 감소
> ex) 5 downTo 0
→ 5, 4, 3, 2, 1, 0

<br>


`step` -> 지정한 값만큼 증가 또는 감소
> ex) 
0..10 step 2
→ 0, 2, 4, 6, 8, 10

### 함수 선언

#### <mark>자바</mark>
```gradle
public int add(int a, int b) {
    return a + b;
}
```

두 개의 int 값을 매개변수로 받아 더한 결과를 반환하는 자바의 함수 선언이다.

<br>
<br>

#### <mark>코틀린</mark>

```kotlin
fun add(a: Int, b: Int): Int {
    return a + b
}
```

위와 같은 의미의 코틀린 문법의 함수 선언이다.

<br>

코틀린에서는 함수 앞에 **fun**을 작성하며,

> fun 함수이름(매개변수: 타입): 반환타입 {}

순서로 작성한다.

<br>

또한, 함수의 내용이 간단한 경우 =을 사용하여 더 짧게 작성할 수도 있다.

```kotlin
ex)
fun add(a: Int, b: Int) = a + b
```

이 경우 a + b의 결과가 자동으로 반환되기 때문에 return을 작성하지 않아도 되다.

### 클래스 선언
#### <mark>자바</mark>

```gradle
public class User {
    private String name;
    private int age;

    public User(String name, int age) {
        this.name = name;
        this.age = age;
    }
}
```

name과 age를 가지고 있는 User 클래스를 선언하고, 생성자를 통해 값을 전달받는 코드이다.

<br>
<br>

#### <mark>코틀린</mark>

```kotlin
class User(
    val name: String,
    val age: Int
)
```

위와 같은 의미의 코틀린 문법의 클래스 선언이다.

이만큼이나 짧아질 수 있다!

<br>

코틀린에서는 클래스의 생성자를 클래스 이름 뒤에 바로 작성할 수 있기에

> class 클래스이름(
    프로퍼티이름: 타입)

이라는 간단한 구조로 작성되며, 생성자로 전달받은 값을 바로 사용할 수 있다.

<br>

```kotlin
ex)

val user = User("이다원", 17)

println(user.name)
println(user.age)
```

즉, 자바처럼 별도로 **필드를 선언하고 생성자에서 this.name = name과 같이 작성하지 않아도 된다는 것이다!**

<br>

#### 그리고 추가로 코틀린은 데이터를 저장하기 위한 클래스를 간단하게 작성할 수 있는 **data class**라는 것이 존재한다.


```kotlin
data class 클래스이름(
    프로퍼티이름: 타입
)
```

형식으로 작성하며, data class를 사용하면 toString(문자열), equals(일치하는지), hashCode(정수 반환) 등의 메서드를 자동으로 만들어주기 때문에 데이터를 저장하는 객체를 간단하게 만들 수 있다.

> Spring에서는 DTO를 만들 때 자주 사용된다.

### 배열

#### <mark>자바</mark>

```gradle
int[] numbers = {1, 2, 3, 4, 5};
```

int형 데이터를 여러 개 저장할 수 있는 배열문이다.

```kotlin
val numbers = arrayOf(1, 2, 3, 4, 5)
```


으로 간단히 변경 가능하다.

### 리스트

#### <mark>자바</mark>

```gradle
List<String> names = new ArrayList<>();

names.add("철수");
names.add("영희");
```

자바의 리스트다.

<br>
<br>

#### <mark>코틀린</mark>

```kotlin
val names = mutableListOf<String>()

names.add("철수")
names.add("영희")
```

위와 같은 의미의 코틀린 문법의 리스트 선언이다.

<br>

코틀린에서는 listOf() 또는 mutableListOf()로 리스트를 사용한다.

> val names = listOf("철수", "영희") 일때,

**listOf()는 값을 변경할 수 없는 리스트**이고

> val names = mutableListOf("철수", "영희")

> names.add("민수")

위와같은 예제에서 확인할 수 있듯 `mutableListOf()`로 값을 추가하거나 삭제할 수 있다.

### Null / Nullable

#### <mark>자바</mark>

```java
String name = null;
```

name이라는 String 변수에 null을 저장하는 자바 문법이다.

<br>
<br>

#### <mark>코틀린</mark> <<중요!

```kotlin
var name: String? = null
```

코틀린에서는 기본적으로 변수에 **null을 저장할 수 없다**.

따라서 null이 들어갈 변수는 타입 뒤에 ?를 붙여서 표기한다.

```kotlin
var name: String? = null
```

여기서 String?은 String또는 null일 수 있다!

라는 의미이다.

<br>

그리고 코틀린에서는 null 변수에 바로 접근할 수 없다.

```kotlin
var name: String? = null

println(name.length) << 오류
```

대신 `?.`을 사용하며,
> println(name?.length)

같은 꼴을 가지고 변수가 null이 아닐 때만 실행하고, null이면 null을 반환해준다.

요약하자면 **프로그램의 안전성**을 높여주는 것이다.

<br>

또한 코틀린에선 NULL에 대해 명시해주는 연산자도 존재한다.


`?`  -> null일 수도 있음   
`?.` -> null인지 확인하고 안전하게 접근   
`!!` -> null이 아니라고 확신하고 접근   

<br>

즉, 대표적으로 예시를 들자면 `name!!.length` 같은 코드는 name이 null이 아니라고 확신하고 length에 접근하라고 명령하는 것이라 할 수 있다.

<br>

하지만 **실제로** name이 **null이라면 오류가 발생**하기 때문에 이 연산자는 반드시 주의해서 사용해야 한다.

### when문

#### <mark>자바</mark>

```java
int a = 2;

switch (a) {
    case 1:
        System.out.println("1입니다");
        break;
    case 2:
        System.out.println("2입니다");
        break;
    default:
        System.out.println("그 외입니다");
}
```

a의 값에 따라 실행할 코드를 나누는 자바의 switch문이다.

<br>
<br>

#### <mark>코틀린</mark>

```kotlin
val a = 2

when (a) {
    1 -> println("1입니다")
    2 -> println("2입니다")
    else -> println("그 외입니다")
}
```

위와 같은 의미의 코틀린 문법의 조건문이다.

<br>

코틀린에서는 자바의 switch문 대신 **when**을 사용하며,

```kotlin
when (변수) {
    값1 -> 실행할 코드
    값2 -> 실행할 코드
    else -> 실행할 코드
}
```

스위치문과 비슷한 위의형식으로 작성한다.

그리고 또한 **when 역시 if문과 마찬가지로 하나의 값으**로 사용할 수 있다.

### 컬렉션 함수

코틀린에서는 리스트와 같은 컬렉션을 처리할 수 있는 다양한 함수를 제공한다.

대표적으로 `forEach`, `filter`, `map` 등이 있다.

<br>

#### <mark>forEach</mark>

```kotlin
val numbers = listOf(1, 2, 3, 4, 5)

numbers.forEach {
    println(it)
}
```

리스트의 각 요소를 하나씩 꺼내서 실행하는 함수이다.

> forEach -> 각각 실행

<br>

#### <mark>filter</mark>

```kotlin
val numbers = listOf(1, 2, 3, 4, 5)

val result = numbers.filter {
    it > 3
}
```

조건을 만족하는 요소만 골라서 새로운 리스트로 반환한다.

예시의 위 코드에서는 3보다 큰 값만 골라내므로 `result → [4, 5]`로 반환된다.

> filter -> 조건에 맞는 것만 골라냄

<br>

#### <mark>map</mark>

```kotlin
val numbers = listOf(1, 2, 3, 4, 5)

val result = numbers.map {
    it * 2
}
```

각 요소를 원하는 값으로 변환하여 새로운 리스트를 만든다.

> map -> 각각의 값을 변환

### 클래스 호출

#### <mark>자바</mark>

```java
public void introduce(String name, int age) {
    System.out.println(name + ", " + age);
}
```

자바에서는 함수를 호출할 때 정의된 매개변수에 맞게 값을 전달해야 한다.

<br> <br>

#### <mark>코틀린</mark>
```kotlin
fun introduce(name: String, age: Int = 17) {
    println("$name, $age")
}
```
하지만 코틀린에서는 매개변수에 기본값을 지정할 수 있다.

> introduce("김다원")

위와 같이 보내도 기본값인 17이 사용된다는 것이다.

<br>

또한 당연하게도 매개변수의 이름을 직접 지정하여 값을 전달할 수도 있다.

> introduce(name = "박다원", age = 17)

### 타입 확인과 형변환

#### <mark>코틀린</mark>


`is`는 코틀린에서 해당 변수의 타입을 확인할 때 사용한다.

예시 코드
```kotlin
val value: Any = "최다원"

if (value is String) {
    println(value.length)
}
```

<br>

`as`는 다른 타입으로 형변환할 때 사용한다.


예시 코드
```kotlin
val value: Any = "김박최다원"

val name = value as String

println(name.length)
````

단, **실제 타입이 맞지 않는 경우 오류가 발생할 수 있으므로 주의해**서 사용해야 한다!
