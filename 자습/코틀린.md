# Kotlin

 자바에 비해 불필요한 코드를 줄여 **가독성과 생산성이 높고, 널로 인해 발생하는 예외를 방지할 수 있는 안전한 타입 시스템을 제공**한다는 장점이 있다고 한다.

### 변수 선언
#### <mark>자바</mark>
```gradle
int a = 5;
String b = "배고파";
final int c = 6;
```
a는 int형 5    
b는 문자열 "배고파"    
c는 int형이고 불변하는 6

이라는 뜻의 자바 변수 선언이다.

<br>
<br>

#### <mark>코틀린</mark>
```kotlin
val a = 5
val b = "배고파"
var c = 6
```
위와 같은 의미의 코틀린 문법의 변수 선언이다.

<br
> 변수이름 : 타입 = 변수  
ex) val i : Int = 5

순서로 작성하는 것이 일반적이나, 위처럼 생략이 가능하다!

<br>
<br>
<br>

### 조건문

#### <mark>자바</mark>

```gradle
int a = 5;

if (a > 3) {
    System.out.println("3보다 크다");
} else {
    System.out.println("3보다 작거나 같다");
}
```

a가 3보다 크다면 "3보다 크다"를 출력하고, 그렇지 않다면 "3보다 작거나 같다"를 출력하는 자바 조건문이다.

<br>
<br>

#### <mark>코틀린</mark>

```kotlin
val a = 5

if (a > 3) {
    println("3보다 크다")
} else {
    println("3보다 작거나 같다")
}
```

위와 같은 의미의 코틀린 문법의 조건문이다.

<br>

코틀린의 if문은 자바와 거의 동일하게 사용할 수 있으며, **System.out.println() 대신 println()을 사용**한다고 한다.

또한 코틀린에서는 if문 자체를 하나의 값처럼 사용할 수 있다!

<br>

예시를 들자면 
```kotlin
val result = if (a > 3) {
    "3보다 크다"
} else {
    "3보다 작거나 같다"
}
```
이 코드가 조건을 충족한다면 result에 "3보다 크다"라는 문자열이 저장된다는 것이다.

당연하게도 충족하지 않는다면 else문으로 내려와 result 값은 "3보다 작거나 같다"가 된다!

### 반복문
#### <mark>자바</mark>

```gradle
for (int i = 0; i < 5; i++) {
    System.out.println(i);
}
```
자바의 for문이다.

<br>
<br>

#### <mark>코틀린</mark>

```kotlin
for (i in 0 until 5) {
    println(i)
}
```

같은 의미의 코틀린 문법의 반복문이다. 

코틀린에서는 자바처럼 초기값; 조건식; 증감식을 작성하지 않고,

> for (변수 in <mark>범위</mark>) {}
형식으로 작성한다.

<br>
<br>

**범위의 문법으로는 아래와 같은 표현식이 있으니 참고해서 사용하도록 하자.**   

`..` -> 시작 값부터 범위 값까지 1씩 증가
> ex) 0..5
→ 0, 1, 2, 3, 4, 5

<br>

`until` -> 시작 값부터 범위 값 미만까지 1씩 증가
> ex) 0 until 5
→ 0, 1, 2, 3, 4

<br>


`downTo` -> 시작 값부터 범위 값까지 1씩 감소
> ex) 5 downTo 0
→ 5, 4, 3, 2, 1, 0

<br>


`step` -> 지정한 값만큼 증가 또는 감소
> ex) 
0..10 step 2
→ 0, 2, 4, 6, 8, 10

<br>
<br>

### 함수 선언

#### <mark>자바</mark>
```gradle
public int add(int a, int b) {
    return a + b;
}
```

두 개의 int 값을 매개변수로 받아 더한 결과를 반환하는 자바의 함수 선언이다.

<br>
<br>

#### <mark>코틀린</mark>

```kotlin
fun add(a: Int, b: Int): Int {
    return a + b
}
```

위와 같은 의미의 코틀린 문법의 함수 선언이다.

<br>

코틀린에서는 함수 앞에 **fun**을 작성하며,

> fun 함수이름(매개변수: 타입): 반환타입 {}

순서로 작성한다.

<br>

또한, 함수의 내용이 간단한 경우 =을 사용하여 더 짧게 작성할 수도 있다.

```kotlin
ex)
fun add(a: Int, b: Int) = a + b
```

이 경우 a + b의 결과가 자동으로 반환되기 때문에 return을 작성하지 않아도 되다.

<br>
<br>
<br>
<br>

### 클래스 선언
#### <mark>자바</mark>

```gradle
public class User {
    private String name;
    private int age;

    public User(String name, int age) {
        this.name = name;
        this.age = age;
    }
}
```

name과 age를 가지고 있는 User 클래스를 선언하고, 생성자를 통해 값을 전달받는 코드이다.

<br>
<br>

#### <mark>코틀린</mark>

```
class User(
    val name: String,
    val age: Int
)
```

위와 같은 의미의 코틀린 문법의 클래스 선언이다.

이만큼이나 짧아질 수 있다!

<br>

코틀린에서는 클래스의 생성자를 클래스 이름 뒤에 바로 작성할 수 있기에

> class 클래스이름(
    프로퍼티이름: 타입)

이라는 간단한 구조로 작성되며, 생성자로 전달받은 값을 바로 사용할 수 있다.

<br>

```kotlin
ex)

val user = User("이다원", 17)

println(user.name)
println(user.age)
```

즉, 자바처럼 별도로 **필드를 선언하고 생성자에서 this.name = name과 같이 작성하지 않아도 된다는 것이다!**
